# Security Policy

## Supported Versions
Only the latest release and active developer branches receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Foundry (venture-studio), please report it responsibly:
- Email: security@foundry.studio
- Do NOT open public GitHub issues for security vulnerabilities.
- Include reproduction steps and threat vector details.
- We will acknowledge receipt within 24 hours and issue a patch within 7 business days.
